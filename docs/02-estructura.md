# Estructura del código

- `include/dsm.h`: las constantes, el struct y los nombres de las funciones.
- `src/dsm.c`: `page_table`, `memory`, `init_page_table`, `leer` y `escribir`.
- `src/main.c`: lee el número del proceso y arranca.
- `Makefile`: con `make` se compila.

Los `.h` dicen qué existe y los `.c` tienen el código.
