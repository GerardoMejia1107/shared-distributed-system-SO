# Mini-simulador de Memoria Compartida Distribuida (DSM)

Proyecto 10 de la cátedra de Sistemas Operativos. Dos procesos (P1 y P2) simulan una memoria compartida a nivel de página y se comunican por sockets TCP.

```
make
./my_dsm 1      # terminal 1
./my_dsm 2      # terminal 2
```

La documentación está en `docs/`. Los pasos del demo, en `docs/09-demo.md`.
